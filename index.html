jr-accessibility

Framework-agnostic accessibility widget. Drop-in, no backend required.

Features

Voice Mode

Hover over any paragraph to hear it read aloud via ResponsiveVoice.

Typography Controls

Adjust text size, line height, letter spacing, alignment, and bold weight.

Visual Modes

High contrast, monochrome, hide images, pause animations — full control.

Magnifier

Cursor-following magnifier lens for enhanced readability.

Translate Page

Translate the entire page into your preferred language via Google Translate.

Virtual Keyboard

On-screen keyboard for users who can't use a physical keyboard.

This image is for testing the Hide Images accessibility feature. Open the accessibility menu and toggle "Hide Images" — this image (and others on the page) should disappear, leaving only the text content visible.

Try It Now

Look at the floating buttons on the left side (desktop) or the FAB button in the bottom-left corner (mobile). Hover over paragraphs to test voice mode.
